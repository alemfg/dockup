fix(v4.0.6): KeyError '5M' on stream:candles handler

ROOT CAUSE
----------
AnalysisContext.candle_history was initialised with a fixed dict:
  {"1M": [], "15M": [], "1H": []}

Workers publish candles for all configured timeframes including 5M and 4H.
When a 5M candle arrived, context_engine.on_candle() did:
  history = ctx.candle_history[timeframe]   # KeyError: '5M'

FIX
---
analysis/context_engine.py:
  - candle_history default changed from a pre-seeded dict to dict()
    (empty — no timeframes assumed).
  - on_candle() now uses ctx.candle_history.setdefault(timeframe, [])
    so any timeframe (1M, 5M, 15M, 1H, 4H, 1D, or any future one)
    is accepted without raising KeyError.

FILES CHANGED
-------------
analysis/context_engine.py
