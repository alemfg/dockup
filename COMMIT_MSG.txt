BREAKING CHANGES
----------------
- brain/brain.py now requires DecisionEngine, RiskManager, PositionTracker, OrderLog
- StreamSubscriber signature extended with decision_engine, position_tracker, order_log, risk_manager
- worker._execute_order() fully replaced — now supports OCO and stop-limit placement

NEW MODULES
-----------
brain/decision/engine.py
  - Reads CR 9AM signals and graph arbitrage paths
  - Applies configurable rules: min score, min RR, BOS/FVG requirements, cooldown
  - Emits OrderCommand to bus in SIMULATE (log-only) or LIVE (send to exchange) mode
  - Per-pair cooldown tracker prevents order spam
  - Checks concurrent order limit before emitting

brain/decision/risk_manager.py
  - Circuit breakers: daily loss, drawdown from peak, consecutive losses
  - Per-exchange and per-pair capital exposure limits
  - Runtime-configurable limits (no restart needed)
  - Manual halt resume via API and dashboard
  - Tracks daily P&L reset at UTC midnight

brain/decision/positions.py
  - Opens a Position on every order fill
  - Updates P&L on every price tick
  - Detects SL hit, TP1 hit (partial), TP2 hit (full close)
  - Notifies order log and risk manager on close
  - Win/loss summary, daily P&L grouping for charts

brain/orders/log.py
  - Full order lifecycle: created → sent → filled → closed
  - Exchange sync reconciliation (updates status from exchange-reported state)
  - Queryable by exchange, pair, status, source
  - Financial summary: win rate, avg P&L, fees, best/worst trade
  - Daily P&L series for charting

WORKER CHANGES
--------------
worker._execute_order():
  - Fully rewritten with CCXT OCO support (Binance, Coinbase, Bybit)
  - Fallback to limit + separate stop-limit for non-OCO exchanges (Kraken etc.)
  - Publishes full OrderResult: fill price, volume, fees, slippage, execution_time_ms
  - Dry-run path returns simulated result without touching exchange

worker._order_sync_loop() [NEW]:
  - Runs every ORDER_SYNC_INTERVAL_S (default 30s) if API key present
  - Fetches open orders and recent closed/cancelled orders via CCXT
  - Publishes each as an order_result with source="exchange_sync"
  - Brain reconciles internal order log from sync data
  - Detects manual orders and external cancellations

FRONTEND PANELS (NEW)
---------------------
FinancialsPanel (💹 Financials tab):
  - Summary stats: total P&L, win rate, trade count, daily loss
  - Risk gauges: daily loss, drawdown, consecutive losses
  - Trade History table with manual close button
  - Cumulative P&L SVG chart (no external chart library required)
  - Shows simulated vs live trade breakdown

RiskPanel (🛡 Risk & Rules tab):
  - Live circuit breaker status with progress bars
  - Inline-editable risk limits (max daily loss, drawdown, exposure)
  - Inline-editable decision engine rules (min score, min RR, capital per trade)
  - All edits apply immediately via PATCH API — no restart needed
  - Manual resume button when system is halted

LogViewerPanel (🖥 Logs tab):
  - WebSocket live tail from brain process
  - In-memory ring buffer (last 2000 lines, capped to avoid memory growth)
  - Level filter: ALL / ERROR / WARNING / INFO / DEBUG
  - Pause / Resume scroll
  - Clear button
  - Reconnects automatically on disconnect
