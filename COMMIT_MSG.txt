BACKEND BUG FIXES
────────────────────────────────────────────────────────────────────────

[CRITICAL] storage/market_state.py — add missing get_open_position_usd()
  The risk manager called this method on every order but it did not exist
  in MarketState. The resulting AttributeError was caught silently and
  treated as a block, causing ALL graph_arb orders to be blocked with
  "Exchange exposure limit" regardless of actual exposure. Fixed by
  implementing the method: scans _order_results for open/pending/partial
  entries matching the given exchange+pair and sums their capital_usd.

[CRITICAL] brain/decision/risk_manager.py — skip exposure check when
  total_usd = 0 (no balance data loaded yet)
  Original code: `if total > 0 and (ex_usd + capital) / total > limit`
  When total=0 on startup (workers haven't reported balances), the
  condition was never True, but total=0 also means the ratio is
  undefined. Now the entire exchange exposure block is skipped when
  total=0 so startup orders are not silently discarded.

[CRITICAL] arbitrage/graph/models.py — fix phantom 50% profit cycles
  Root cause: some exchanges (LBank, MEXC) report certain pairs in a
  non-USDT denomination, producing effective_rate values like 99.9 for
  KAVA/USDT (real price ~$0.6). This leaked through the old clamp of
  min(1.5, product), producing fake +50% gross_product cycles.
  Fix — three layered guards:
    1. Per-edge check: any effective_rate > 200 → return 0.0 immediately
    2. log-space guard: -log_sum > 3 (≡ exp(3)≈20x) → return 0.0
    3. Final clamp: min(1.05, product) — max 5% gross, not 50%
  Real triangular arb on CEX does not exceed ~3% gross. New-listing
  spikes handled by the listings module, not graph arb.

FRONTEND — ALERT SYSTEM
────────────────────────────────────────────────────────────────────────

[NEW] frontend/src/components/AlertBanner.jsx — global alert strip
  Injected between StatusBar and page content. Visible on every tab.
  Polls /api/system/status + /api/fleet/workers + /api/graph/paths
  every 5s. Shows compact coloured banners for:

    ⚡ GREEN  — profitable cycles detected (count + best path detail)
               "View →" button navigates directly to Graph Arb tab
    ⛔ RED    — worker blocked (ip_block / status=blocked)
    🔑 RED    — auth error on exchange (navigates to Security tab)
    ⚠  YELLOW — high error count on worker (>10 errors)
    🚦 YELLOW — rate limiting active (429s)
    🕐 YELLOW/RED — stale price contexts above threshold
    🛑 RED    — risk system HALTED (navigates to Risk & Rules tab)

  Each alert is individually dismissable (×). Dismissed alerts
  re-surface automatically if the underlying condition changes
  (e.g. a new profitable cycle fires after the old one was dismissed).

[FIX] frontend/src/App.jsx — wire AlertBanner + unified navigateTo()
  Replaced inline `setTab(t.id); setSelectedWorker(null)` with a
  shared navigateTo() function, allowing AlertBanner's "View →" buttons
  to deep-link into the correct tab from any page.

FRONTEND — GRAPH VISUALIZATION
────────────────────────────────────────────────────────────────────────

[NEW] CycleGraph component — clean circular path diagram
  Renders a single arbitrage cycle as a minimal SVG ring: asset nodes
  arranged in a circle, green directed arrows between them, exchange
  name and effective_rate on each edge. No force layout, no noise.
  Shown inside each expanded PathCard so the cycle is immediately
  readable without the full graph hairball.

[NEW] "Isolate cycles" toggle on Currency Graph card
  When active: filters the full force-directed graph to show ONLY nodes
  and edges that participate in at least one profitable cycle.
  Dramatically reduces noise when 60+ nodes are present. Toggle
  highlights green when active. Subtitle updates to reflect mode.

[NEW] Execution steps section in expanded PathCard
  Numbered step-by-step action guide per path:
    1. BUY  <from> → <to>  on <exchange>  ×rate  -fee%
    2. SWAP ...
    n. SELL ...
  Cross-exchange transitions are flagged with a ⟳ transfer warning
  showing which asset needs to move between which exchanges before
  the next leg can execute. Makes manual verification of a path
  instant without reading the raw edge table.
