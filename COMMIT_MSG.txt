BUGS FIXED
----------

1. Brain crash on startup: DecisionEngine.__init__() unexpected keyword 'alert_sender'
   brain/decision/engine.py: added alert_sender=None optional parameter.
   Was wired in brain.py but never declared in DecisionEngine.__init__.

2. Binance order sync: rate limit WARNING on fetchOpenOrders without symbol
   worker/worker.py: sync now fetches per-pair instead of a global call.
   Also sets ccxt option warnOnFetchOpenOrdersWithoutSymbol = False.

3. Kraken order sync: fetchOrders() not supported
   worker/worker.py: exchanges in no_fetch_orders set (kraken, kucoin, okx, huobi, gate)
   now skip fetch_orders() and only call fetch_open_orders() per pair.

4. docker-compose.yml: obsolete `version: "3.9"` attribute warning
   Removed version field entirely (Docker Compose v2 ignores it).

5. make docker-worker-logs only showed binance
   Makefile: docker-worker-logs now tails all workers (binance, kraken, uniswap).
   Added per-exchange targets: docker-worker-logs-binance, docker-worker-logs-kraken,
   docker-worker-logs-uniswap, and docker-logs-all.

WORKER CONTROLS
---------------

api/routes/workers.py: new endpoints
  POST /workers/{id}/pause     — suspend ticks, worker stays connected
  POST /workers/{id}/resume    — resume a paused worker
  POST /workers/{id}/reload    — reload config for specific worker
  POST /workers/{id}/restart   — restart specific worker
  POST /workers/{id}/kill      — kill specific worker
  POST /workers/all/reload     — broadcast reload to all workers
  POST /workers/all/kill       — broadcast kill to all workers

worker.py:
  - _paused flag: pause/resume commands suspend _collect_and_publish
  - heartbeat reports "paused" status when paused
  - reload_config, pause, resume all handled in _command_listener
