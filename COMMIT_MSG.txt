ARBX v4.2.0 — Tooltips · Graph Visualization · .env Hot-Reload Fix

── Bug Fixes ───────────────────────────────────────────────────────────────────

[FIX] config/loader.py — reload_config() now calls load_dotenv(override=True)
  before clearing the cache. This means API keys added to .env after startup
  (e.g. BINANCE_API_KEY) are picked up immediately when "Reload Brain Config"
  or "Reload Workers Config" is pressed. Previously only config.yaml was
  re-read; .env was loaded once at module import and never refreshed.

── New Feature: Graph Arb Visualization ────────────────────────────────────────

GraphPanel.jsx completely rewritten with:
  - Pure-SVG force-directed graph (no external deps)
    · Nodes laid out by iterative force simulation (repulsion + spring + gravity)
    · Responsive — ResizeObserver tracks container width
    · Colour-coded nodes per asset: BTC=orange, ETH=blue, USDT=green,
      BNB=yellow, SOL=purple, XRP=cyan, ADA=indigo, others=grey
  - Edge colour coding:
    · Green     = part of a profitable cycle (from top paths list)
    · Yellow    = marginal (rate near 1.0)
    · Red       = unprofitable direction
    · Grey      = stale data
    · Green edges are thicker (2.5px) and more opaque
    · Nodes in profitable cycles get a dashed outer ring
  - Animated directed arrows (SVG markers, colour-matched)
  - Hover tooltip on edges: shows From→To, exchange, rate, fee, stale flag
  - Graph defaults to visible; toggle with Hide/Show button
  - Legend below graph explains all four colours
  - PathCard profit colours:
    · Green (> 0.5%)  · Yellow (> 0%)  · Red (negative)
    · Best profitable path gets green border
  - All profit breakdown pills (gross, fees, gas) have hover tooltips
  - Hop count has tooltip explaining multi-hop mechanics
  - Raw edges table moved behind "Show raw edges" toggle (was always visible)
