fix(v4.0.2): brain crash — StreamSubscriber missing alert_sender parameter

BUGS FIXED
----------

After fixing DecisionEngine in v4.0.1, the same missing-parameter pattern
existed in StreamSubscriber.__init__().

brain.py passes alert_sender=self.alert_sender to StreamSubscriber but
the constructor only accepted: bus, market_state, context_engine,
auth_manager, config, currency_graph, decision_engine, position_tracker,
order_log, risk_manager.

Fix: added alert_sender=None as an optional parameter to StreamSubscriber.
Stored as self._alert for future use (wiring SL/TP/opportunity alerts).

Verified all other constructors brain.py calls (RiskManager, PositionTracker,
AlertSender, PersistenceLayer, FleetMonitor, ContextEngine) — none have
the same issue.

Root cause: brain.py was updated programmatically to add alert_sender= to
constructor calls, but the downstream class signatures were not updated
at the same time.

FILES CHANGED
-------------
brain/stream/subscriber.py — added alert_sender=None to __init__
