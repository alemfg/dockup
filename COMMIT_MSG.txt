NTFY / ALERTS BUG FIX (alerts/sender.py)
──────────────────────────────────────────
Root cause: _send_ntfy() used self._session bare — when called directly
from the /alerts/test/{channel} route (bypassing the queue drain loop),
self._session could be None if start() hadn't been called yet, causing
AttributeError. Also: data=str was passed instead of data=bytes.
Fix: added _get_session() helper — creates a temporary one-shot aiohttp
session when the shared session is None or closed. Every _send_*() method
now uses this helper and closes the temp session when done. Also fixed
data=alert["message"].encode() for ntfy POST body.
