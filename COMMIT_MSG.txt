v6.9 — UI Stability & Bug Fixes

CRITICAL FIXES
──────────────
usePolling infinite re-render loop (root cause of ALL spinner/blink bugs)
  • Inline arrow functions passed as fetchFn created a new reference on
    every render, causing useEffect to re-fire continuously.
  • Fix: store fetchFn in a useRef inside the hook. Effect deps are now
    [interval, tick] only — both primitives that change only intentionally.
  • Affected panels fixed: Vault, Fleet Events, Listings, Orders (all blink
    and spinner-loop issues resolved by this single fix).

500% phantom arbitrage path
  • math.exp(-log_sum) overflowed when log_sum was a large negative number
    (caused by a stale or inverted rate in the graph). The result was clamped
    to 6.0 (500%) and displayed as a real opportunity.
  • Fix: if -log_sum > 20 (exp would exceed ~485M), return 0.0 (unprofitable)
    instead of clamping. Upper cap lowered from 6.0 to 1.5 (50%) — no real
    CEX arb exceeds this; genuine new-listing premiums stay visible.
  • ArbitragePath.to_dict() now includes is_stale and max_edge_age_s fields.

Decision engine log spam (4500+ blocked orders in hours)
  • graph_arb on_graph_path fired every 5s, cooldown only set on PASS,
    so the same blocked order was logged on every scan tick.
  • Fix: cooldown is now set even on blocked orders, throttling re-logging
    of the same risk-blocked signal to once per cooldown window.
